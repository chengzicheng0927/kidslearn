# 主聊天界面(ChatView)优化需求

> 目标：提升答题界面的趣味性、美观性和儿童吸引力，优化答题流程体验。
>
> 日期：2026-04-01

---

## 一、现有架构梳理

### 页面结构

```
ChatView.vue（三面板左右滑切换）
├── ChatHeader.vue          ← 空的 8px 占位，无实际内容
├── ComboFireBar.vue        ← 连击弹幕（右→左飘过）
├── DailyTaskCard.vue       ← 今日任务双环进度
├── ChatTimeline.vue        ← 滚动答题区
│   ├── 粒子背景（12个浮动气泡）
│   ├── 老师引导语卡片
│   └── QuizCard.vue        ← 核心答题卡片
│       ├── ThinkingModal.vue  ← 批改中动画
│       └── ResultModal.vue    ← 答对/答错结果弹窗
├── 导航圆点指示器
├── InputBar.vue            ← 底部输入栏 + FAB菜单
├── VoiceOverlay.vue        ← 语音输入浮层
├── EyeCareReminder.vue     ← 护眼提醒（每10题）
├── RestReminderModal.vue   ← 休息提醒（15分钟）
├── StarFlyAnimation.vue    ← 星星飞升动画
└── MilestoneModal.vue      ← 里程碑弹窗（已实现但未接入触发）
```

### 答题流程

```
加载题目 → 展示 QuizCard → 点击选项 → ThinkingModal(批改中1.5s+)
    → 选项变色(正确绿/错误红) → ResultModal(星星/XP/解析)
    → 点击"继续" → 加载下一题 → 循环直到完成
```

### 激励系统

| 功能 | 触发条件 | 效果 |
|------|---------|------|
| 星星飞升 | 答对题目 | 1-5颗星飞向顶部 |
| 连击弹幕 | combo >= 2 | 右→左飘过的弹幕 |
| 宠物心情 | combo 3+/5+ | 宠物变为 clingy/happy |
| 护眼提醒 | 每10题 | 绿色弹窗 |
| 休息提醒 | 15分钟无交互 | 黄色弹窗 |
| 里程碑 | ⚠️ 未接入 | 全屏庆祝动画 |

## 二、现有问题分析

### 2.1 视觉设计问题

| # | 问题 | 影响 |
|---|------|------|
| V1 | **ChatHeader 是空的 8px 占位**，浪费了顶部黄金区域，页面没有沉浸感入口 | 儿童看不到当前进度、角色形象，缺少"在玩游戏"的感觉 |
| V2 | **答题卡片（QuizCard）样式偏传统**，torn-paper 边框风格更像卷子不像游戏 | 缺少冒险/闯关/游戏化的视觉氛围 |
| V3 | **选项 2x2 网格排列单调**，四个选项只有颜色不同，缺乏互动暗示 | 儿童不清楚"这是可以点的按钮"，缺少点击反馈预期 |
| V4 | **粒子背景太微弱**（5-10px 半透明气泡），在内容密集时几乎看不到 | 场景氛围感不足 |
| V5 | **导航圆点指示器太小**（6px），儿童很难注意到可以滑动切换 | 日历/宠物面板发现率低 |
| V6 | **缺少角色/IP 形象常驻**，只有 QuizCard 中有一个小狐狸图片 | 缺少情感连接，"小星老师"只是文字没有可视形象 |

### 2.2 答题流程问题

| # | 问题 | 影响 |
|---|------|------|
| F1 | **ThinkingModal 强制 1.5 秒等待**，打断答题节奏 | 连续答题时感觉卡顿，儿童容易不耐烦 |
| F2 | **ResultModal 需要手动点"继续"**，没有自动推进选项 | 增加操作步骤，答对时不需要看解析，应该快速跳过 |
| F3 | **答错后只有文字解析**，没有动画或互动式纠正 | 错题的学习效果弱，儿童容易跳过不看 |
| F4 | **历史答题堆积在 Timeline 中**，答题越多页面越长越卡 | 上下文过多，新题被淹没，滚动体验差 |
| F5 | **学科切换要点击 DailyTaskCard 的环形图**，入口不明显 | 儿童可能不知道可以切换英语/数学 |
| F6 | **完成所有题目后只有一句文字提示**，缺乏庆祝感 | 完成感不足，缺乏"通关"仪式 |

### 2.3 激励系统问题

| # | 问题 | 影响 |
|---|------|------|
| M1 | **MilestoneModal 已实现但未接入触发逻辑** | 浪费了已开发的庆祝功能 |
| M2 | **连击弹幕（ComboFireBar）飞过即消失**，没有累计展示 | 儿童无法回顾自己的连击成就 |
| M3 | **星星只有飞升动画，没有明确的"存到哪里"** | 缺少"收集"感，星星飞完就没了 |
| M4 | **答对反馈单一**（绿色+pop动画），缺乏惊喜变化 | 重复答题后激励效果递减 |
| M5 | **缺少阶段性目标可视化**，虽然有"第N阶段"但不清楚距离下一阶段还有多远 | 缺乏"再答X题就能解锁"的拉力 |

### 2.4 交互体验问题

| # | 问题 | 影响 |
|---|------|------|
| I1 | **左右滑动切换面板阈值 25%**，容易误触 | 答题时横向滑动可能意外切走 |
| I2 | **FAB 菜单把"清空会话"放在了弧形菜单中**（dev模式），生产环境也有入口 | 儿童可能误触清空所有进度 |
| I3 | **文字输入框在答题模式下无用**，儿童答题是选择题不需要打字 | 底部空间被浪费，应该根据上下文显示/隐藏 |
| I4 | **语音输入3秒超时太短**，小朋友说话慢 | 语音识别经常提前关闭 |

## 三、优化方案

### P0 - 核心体验（高优先级）

#### 3.1 答题卡片重设计

**目标**：把"做试卷"的感觉变成"玩游戏"

- [ ] 将 QuizCard 重新设计为**游戏卡牌**风格
  - 移除 torn-paper 边框，改用圆角 20px + 微渐变背景 + 轻柔阴影
  - 题目区域增加主题插图/小 icon（如英语题显示字母气泡，数学题显示数字方块）
  - 选项改为**大面积可触摸的圆角按钮**，有按下态（scale 0.97 + 加深颜色）
  - 选项间距加大，防止误触（最小 touch target 48px）
- [ ] 选项增加**微交互**
  - hover/touch 时轻微浮起（translateY -2px + 阴影加深）
  - 选中后有**波纹扩散**动画
  - 答对时选项变身彩虹色 + 弹跳 + 撒花粒子
  - 答错时温和的左右晃动 + 正确答案高亮闪烁提示

#### 3.2 优化答题节奏

**目标**：减少等待，让"答对"的快感即时爆发

- [ ] **答对 → 快速通过模式**
  - 答对后直接在卡片内展示结果（绿色对勾 + 星星 + 鼓励语），无需弹出 ResultModal
  - 1.5 秒后自动加载下一题（不需要点"继续"）
  - 连续答对时节奏越来越快（1.5s → 1.2s → 1.0s）
- [ ] **答错 → 沉浸式纠正**
  - 保留 ResultModal，但增加**互动纠正**：
    - 展示正确答案后要求儿童**点击正确选项确认**（加深记忆）
    - 或展示动画演示解题思路（尤其数学题）
  - "听老师讲解" TTS 按钮增加老师角色动画
- [ ] **缩短 ThinkingModal 时间**
  - 如果后端响应 < 500ms，直接跳过 ThinkingModal
  - 最长展示 1 秒即可，不需要强制 1.5 秒

#### 3.3 进度与激励可视化

**目标**：让儿童时刻知道"我在哪，下一站在哪"

- [ ] **顶部进度条取代空 ChatHeader**
  - 显示当前题号 / 总题数（如 `3 / 8`）
  - 进度条用彩色填充 + 小角色在进度条上行走
  - 到达里程碑节点（如第5题）时显示小旗帜/星星 icon
- [ ] **星星收集可视化**
  - 星星飞升后落入顶部的星星计数器（有入袋动画）
  - 星星计数器显示 `⭐ 12 / 20`（今日已获 / 目标）
- [ ] **阶段进度地图**（可选，P1）
  - DailyTaskCard 区域改为横向的**关卡地图**
  - 每道题是一个节点，答对亮起，答错标红，未答灰色
  - 整体像一条弯弯曲曲的小路，终点有宝箱

#### 3.4 接入 MilestoneModal 触发

- [ ] 答题数达到里程碑时触发（如总计 50/100/500 题）
- [ ] 连击达到新纪录时触发
- [ ] 日历打卡连续 3/7/14/30 天时触发
- [ ] 完成当日所有任务时触发**全屏庆祝动画**（代替当前的文字提示）

---

### P1 - 氛围与沉浸（中优先级）

#### 3.5 角色 IP 常驻

- [ ] "小星老师"设计可视角色形象（可复用 ThinkingModal 中的老师 SVG）
  - 常驻在顶部进度条旁边或 DailyTaskCard 区域
  - 根据答题状态切换表情：思考→批改中，开心→答对，鼓励→答错
  - 可以加入简短的文字气泡："加油！""太棒了！""没关系，再来！"
- [ ] 考虑增加**答题陪伴感**
  - 如另一个小动物坐在屏幕角落看你答题
  - 答对时它鼓掌，答错时它安慰

#### 3.6 场景氛围升级

- [ ] **粒子背景增强**
  - 增加粒子种类：星星形状、爱心、音符（英语）、数字（数学）
  - 答对时粒子爆发加速 2 秒
  - 粒子数量随连击数增加
- [ ] **学科主题场景**
  - 英语：蓝天白云 + 字母气泡场景
  - 数学：绿色森林 + 数字方块场景
  - 用 CSS 渐变 + 主题 SVG 插图实现，不用大图片（避免加载慢）
- [ ] **音效系统**（依赖 iOS WebView 能力）
  - 答对：叮咚 + 欢呼
  - 答错：柔和的"嗯"
  - 连击：递增音阶
  - 完成：胜利号角

#### 3.7 历史答题优化

- [ ] **折叠历史答题记录**
  - 默认只显示当前题 + 最后一道已答题的缩略
  - 可以向上滑动展开历史，但默认收起
  - 减少 Timeline 的 DOM 数量，提升滚动性能
- [ ] 或改为**单卡片模式**
  - 一次只显示一道题，像翻卡片一样
  - 答完自动翻到下一张
  - 更聚焦、更有"闯关"感

---

### P2 - 精细打磨（低优先级）

#### 3.8 交互优化

- [ ] **左右滑动切换**增大阈值到 35%，或改为边缘触发
  - 仅从屏幕左/右 20px 区域开始的滑动才触发面板切换
  - 防止答题时的水平滑动误触
- [ ] **底部 InputBar 上下文适配**
  - 答题模式下隐藏文字输入框，只保留 FAB 菜单
  - 或将 InputBar 替换为简洁的底部导航栏（答题/日历/宠物 三个tab）
- [ ] **移除"清空会话"按钮**的生产入口
  - 仅在开发环境（`USE_MOCK=true`）时显示
- [ ] **语音输入优化**
  - 超时时间从 3 秒延长到 5 秒
  - 增加"再说一遍"按钮

#### 3.9 性能优化

- [ ] **虚拟滚动**：quizHistory 超过 20 条时启用虚拟列表
- [ ] **图片懒加载**：QuizCard 中的狐狸图片和题目插图延迟加载
- [ ] **组件懒加载**：ThinkingModal / ResultModal / MilestoneModal 等弹窗组件 defineAsyncComponent

## 五、设计参考

### 目标体验关键词

- **游戏化**：不是做题，是闯关
- **即时反馈**：每一步操作都有视觉和听觉响应
- **收集感**：星星、徽章、里程碑形成收集体系
- **陪伴感**：角色在身边，不是冷冰冰的界面
- **成就感**：清晰的进度，看得到的成长

### 同类产品参考

| 产品 | 值得借鉴的点 |
|------|------------|
| Duolingo | 答对后的即时动效、连击火焰、每日目标环 |
| Khan Academy Kids | 角色陪伴、鼓励性语音、彩色卡片风格 |
| 叽里呱啦 | 闯关地图、奖杯收集、场景化答题 |
| 洪恩识字 | 游戏化题型、动画角色互动、音效丰富 |

## 六、验收标准

- [ ] 儿童（4-8岁）首次使用能自主完成3道题以上，无需家长指导
- [ ] 答对后到下一题的平均等待时间 < 2 秒
- [ ] 连续答题 10 道后，仍有持续的新鲜感（动效变化、鼓励语变化）
- [ ] 顶部进度可视化，儿童能说出"还剩几道题"
- [ ] 完成当日任务时有明确的"通关庆祝"体验
