# 历史计划展开功能 - 需求文档

**创建日期**：2026-03-28
**状态**：✅ 已完成

---

## 1. 需求概述

在家长模式页面，活跃计划提示栏右侧添加展开按钮，点击后瀑布效果展开历史计划列表，支持左右切换浏览不同计划，已完成计划显示"已完成"印章效果。

---

## 2. 用户故事

**作为家长**，我希望在查看当前计划的同时，能够展开查看历史学习计划，方便回顾孩子的学习历程。

---

## 3. 页面位置

- 页面：`kl-ui/src/views/ParentModeView.vue`
- 位置：活跃计划提示栏（`.active-plan-banner`）最右侧

---

## 4. 功能需求

### 4.1 展开按钮
- 位置：活跃计划提示栏最右边
- 样式：圆形按钮，箭头图标（» 展开 / ∧ 收起）
- 交互：点击切换展开/收起状态

### 4.2 展开面板（瀑布效果）
- 动画：从上方滑入，高度从 0 展开到内容高度
- 动画时长：300ms
- 动画效果：ease-out

### 4.3 历史计划列表
- 数据来源：`useParentState` 的 `planHistory`
- 展示形式：与聊天区域一致，使用 `ChatCard` 组件（style="plan"）
- 卡片内容：
  - 标题：计划周期 + 科目（如 "14天英语学习计划"）
  - 信息行：周期天数、难度
  - 阶段列表：各阶段概览
  - 操作按钮：查看详情、调整、取消

### 4.4 计划切换
- 左右箭头按钮切换上一个/下一个计划
- 显示当前索引：如 "2/5"
- 边界处理：到边界时箭头禁用/隐藏

### 4.5 已完成计划印章
- 仅针对 `status === 'completed'` 的计划
- 印章样式：
  - 文字："已完成"
  - 颜色：红色或紫色（#c62828 或 #7c6df8）
  - 角度：旋转 -15 度
  - 位置：卡片右上角
  - 边框：双线边框
  - 透明度：0.8

---

### 新增组件

  - 路径：`kl-ui/src/components/ParentMode/PlanHistoryPanel.vue`

### 修改组件
- `ParentModeView.vue`：添加展开按钮和面板容器

## 6. 数据流

```
ParentModeView
  ├── useParentState
  │     ├── planHistory: LearningPlan[]  // 历史计划列表
  │     └── activePlan: LearningPlan      // 当前活跃计划
  └── PlanHistoryPanel
        ├── props: planHistory, currentIndex
        └── emit: indexChange, close
```
