## 3. API 设计

### 3.1 获取计划详情

**接口**：`GET /api/parent/plan/{planId}`

**请求**：
- Path: `planId` - 计划 ID

**响应**：
```json
{
  "data": {
    "id": "uuid",
    "subject": "en | ma",
    "status": "pending | active | paused | completed | cancelled",
    "difficulty": "easy | medium | hard",
    "durationDays": 14,
    "dailyGoal": "每天5道英语题",
    "phases": [
      {
        "dayRange": "1-7",
        "topic": "动物词汇",
        "goal": "掌握10个动物词汇",
        "questionsPerDay": 5,
        "difficulty": "easy",
        "questions": [
          {
            "id": "uuid",
            "icon": "🐱",
            "question": "cat",
            "options": ["猫", "狗", "兔子", "鸟"],
            "answer": "猫"
          }
        ]
      }
    ],
    "estimatedMinutes": 20,
    "startedAt": "2026-03-25",
    "completedAt": "2026-04-08",
    "totalCompleted": 70,
    "totalCorrect": 60,
    "accuracy": 85.7
  }
}
```

**说明**：
- 题目列表只返回已完成的题目（completed 计划才有意义）
- `answer` 字段只对 completed 计划返回（用于展示正确答题）

### 3.2 调整计划题目

**接口**：`POST /api/parent/plan/{planId}/adjust-questions`

**请求**：
```json
{
  "removedQuestionIds": ["uuid1", "uuid2"]
}
```

**响应**：
```json
{
  "data": {
    "success": true
  }
}
```

**说明**：
- 只对 `pending` 和 `active` 状态的计划开放
- `completed` 状态不允许修改
