# 前端主聊天界面优化计划

## 目标

提升儿童学习体验，增加聊天答题界面的趣味性、视觉美感和交互细节。

---

## 一、趣味性增强

### 1.1 答题反馈动效

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 答对庆祝动画 | 答对后屏幕撒星星/烟花动效，配合鼓励语 |
| P0 | 答错安慰动效 | 答错后宠物或气泡有失落动画，但不打击信心 |
| P1 | 连击激励 | combo >= 3 时触发特殊庆祝（如屏幕震动 + 文字弹出） |
| P1 | 进度条前进动画 | 题目切换时进度条平滑过渡 |

**技术方案**：使用 CSS animation + Vue transition，可复用 Lottie（ios 已有 lottie-overlay）

### 1.2 奖励弹出

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 星星获得弹窗 | 答对后弹出 "+X ⭐" 动画，从答题位置飞向顶部星星 |
| P0 | 徽章解锁提示 | 解锁新徽章时显示小弹窗（已有组件可复用） |
| P1 | 连击奖励弹窗 | combo 触发 reward 模式时特殊弹窗样式 |

### 1.3 宠物互动

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P1 | 宠物状态随答题变化 | 连续答对时宠物开心；答错时宠物担忧 |
| P1 | 宠物参与答题反馈 | 宠物在气泡旁做动作（如跳一跳、摇头晃脑） |

---

## 二、视觉美感增强

### 2.1 聊天气泡优化

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | AI 气泡样式 | 更圆润、更有亲和力的气泡设计，区别于普通聊天 |
| P0 | 选项卡片设计 | 选项 A/B/C/D 改为更有趣的卡片样式，支持点击态 |
| P1 | 气泡打字机效果 | AI 回复逐字显示，增强等待时的期待感 |
| P1 | 气泡表情支持 | 选项支持 emoji 前缀，增强辨识度 |

### 2.2 背景与布局

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 沉浸式背景 | 英语/数学切换时背景渐变平滑过渡 |
| P0 | 顶部进度区域 | 星星数、连击数、进度条区域视觉优化 |
| P1 | 底部输入区 | 发送按钮、语音按钮样式美化 |

### 2.3 颜色与主题

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P1 | 科目主题色 | 英语蓝色系、数学绿色系，贯穿整个聊天界面 |
| P1 | 暗色模式支持 | 可选深色主题，适合夜间使用 |

---

## 三、细节优化

### 3.1 交互细节

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 选项点击反馈 | 点击选项时立即视觉反馈（放大/变色），防止重复点击 |
| P0 | 提交中状态 | 提交答案时选项区显示 loading，防止重复提交 |
| P1 | 答题超时提示 | 倒计时结束时轻柔提示（颜色变化/闪烁） |
| P1 | 滑动返回 | 左滑可返回上一页（如果有上一题上下文） |

### 3.2 空状态与边界

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 加载状态 | 获取题目时骨架屏或小动画 |
| P0 | 无题可答 | 题库答完后友好提示（"今日目标已完成，太棒了！"） |
| P1 | 网络错误重试 | 提交失败时显示重试按钮 |

### 3.3 无障碍与可访问性

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P1 | 字体大小调整 | 支持更大字体选项 |
| P1 | 按钮对比度 | 确保 WCAG AA 标准 |
| P2 | 语音读题 | 支持语音朗读题目（可复用 ios SpeechManager） |
