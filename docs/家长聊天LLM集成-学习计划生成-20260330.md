# 家长聊天 LLM 集成 - 学习计划生成

> **功能**：通过家长聊天界面，AI 智能生成个性化学习计划

**创建日期**：2026-03-30
**状态**：待开发
**优先级**：P0

---

## 1. 需求概述

### 1.1 用户故事

**作为** 家长的我
**想要** 通过聊天告诉 AI 我希望孩子学什么
**以便** AI 自动生成一个适合孩子年龄、年级的个性化学习计划，包含题目和解析

### 1.2 核心能力

| 能力 | 实现方式 | 说明 |
|------|---------|------|
| 智能提示词构建 | LLM | 根据孩子年龄、当前学习阶段、中国大陆学制自动构建 prompt |
| 学习计划生成 | LLM Tool | LLM 生成结构化学习计划（含阶段、目标、难度） |
| 题目生成 | LLM Tool | LLM 生成题目（含题目、选项、正确答案、解析） |
| 计划持久化 | LLM Tool | 调用 tool 保存到 `learning_plans` 和 `questions` 表 |
| 确认激活计划 | **应用层 API** | 复用现有 `POST /api/parent/plan/confirm`，无需 LLM |
| 聊天式交互 | LLM | 支持多轮对话，询问细节，生成/调整计划 |

> **注意**：`confirm_plan` 只是将 `learning_plans.status` 从 `pending` 改为 `active`，属于状态变更操作，直接调用 `PlanService.confirmPlan()` 即可，无需经过 LLM。

### 3.5.3 年级询问 Prompt

```java
public static String gradeInquiryPrompt() {
    return """
    当家长要求生成学习计划，但未提供孩子年级时，按以下流程处理：

    1. 判断是否缺少年级信息
       - 如果 childId 存在但 grade 为空，需要询问
       - 如果是新建聊天，无法确定孩子，需要询问

    2. 询问方式（友好自然）：
       - "好的！请问{childName}现在上几年级了？"
       - "了解！我想为孩子制定一个合适的学习计划，方便告诉我他/她现在上几年级吗？"

    3. 家长回答后，提取年级信息
       - "二年级" → grade = "2年级"
       - "小学二年级" → grade = "2年级"
       - "Grade 2" → grade = "2年级"

    4. 调用 update_child_grade 工具保存年级
       然后继续生成学习计划
    """;
}
```

## 7.1 对话历史支持（新增）

> **目标**：支持多轮对话，LLM 能够记住上下文（如已确认的年级信息）

### 7.1.1 存储方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| Redis | 快速、支持过期 | 需要额外部署 |
| 数据库 | 简单、持久化 | 稍慢 |
| 前端传递 | 无后端改动 | 每次请求带大量数据 |

**选择**：数据库存储（`chat_conversations` 表）

### 7.1.2 对话历史表设计

```sql
-- chat_conversations 表（新增）
CREATE TABLE chat_conversations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    parent_id UUID NOT NULL,
    child_id UUID,
    role VARCHAR(20) NOT NULL,           -- 'user' / 'assistant'
    content TEXT NOT NULL,                -- 对话内容
    tool_calls JSONB,                     -- tool 调用记录（可选）
    tool_results JSONB,                   -- tool 返回结果（可选）
    created_at TIMESTAMP DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_chat_parent ON chat_conversations(parent_id, created_at);
```

### 7.1.3 配置项


## 8. 验收标准

| 场景 | 预期结果 |
|------|---------|
| 首次聊天，孩子无年级 | AI 询问"请问孩子上几年级了？"，家长回答后年级存入数据库 |

| 生成题目 | 每阶段（7天）生成 50-100 道题目，每天 10-20 道 |
| 题目格式 | 包含题目、选项(A/B/C/D)、正确答案、解析、鼓励语 |
| 家长确认计划 | 前端调用 `POST /api/parent/plan/confirm`，状态变为 active |

## 9. 风险与注意事项

| 风险 | 缓解措施 |
|------|---------|
| LLM 生成题目格式不规范 | Tool 输入做严格 JSON Schema 校验 |
| 题目生成量大（50-100题/阶段） | 允许较长响应时间，可异步处理或批量生成 |
| 儿童信息缺失 | 要求必须传入 childId 或 childAge |
| Tool 调用嵌套过深 | 限制最大 Tool 调用次数为 3 次 |
